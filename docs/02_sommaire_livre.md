# VALOMBRE — Sommaire complet du livre

## Architecture en trois niveaux

Le livre est organisé en trois niveaux de lecture :

1. **Vue de pilotage** — ce que le MJ doit savoir en 5 minutes

# PARTIE VI — SCÉNARIO 3 : LA DAME DE LA SPIRALE

## 22. Vue d'ensemble
- Résumé en une page
- Objectifs de l'acte
- Niveaux 9-12 · 4-6 séances
- Révélations indispensables : (1) les vérités sur Sealine fissurent la Larme, (2) la Larme est le catalyseur, (3) le choix final appartient aux PJ
- Fronts actifs pendant ce scénario (tous convergent)
- Le final en entonnoir : pourquoi c'est voulu

## 23. Acte I — Le Sommet
- Scène de boss : Le Vortex (3 phases)
  - Phase 1 : Archimage Épuisé
  - Phase 2 : Larme se Fissure (les vérités comme armes)
  - Phase 3 : Épuisement
- Scène de dilemme : La Conversation à Trois

## 24. Acte II — L'Épilogue
- Scène de conclusion : Le Monde d'Après
- Final variable selon les alliances (voir annexe)

## 25. Les trois choix finaux
- Détruire la Larme : Sealine perdue, sceau refermé
- Sauver Sealine : seuil partiellement ouvert, Valombre changée
- Laisser Thade ouvrir : Spirale déferle, monde transformé
- Tuer Thade sans résoudre la Larme : victoire incomplète

## 26. Final variable selon les alliances
- Si Olane est vivante : elle ouvre un accès
- Si les Loyalistes sont retournés : une partie de la Tour se rend
- Si Mara est alliée : la Résistance attaque ailleurs
- Si Thorgar est convaincu : les rites stabilisent le vortex
- Si Maelric est convaincu : Caldris retarde la quarantaine
- Si le Champion est libre : il tente une purge pendant le final
