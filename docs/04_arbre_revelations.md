# VALOMBRE — Arbre des révélations de la campagne

Cet arbre trace tous les indices de la campagne, leur origine, leur usage et leur rôle dans le final. Le MJ l'utilise pour vérifier que les PJ ont bien les révélations indispensables à chaque étape.

## Chemins de découverte alternatifs

L'arbre ci-dessus suppose un chemin "standard". Voici les canaux alternatifs si les PJ manquent un indice indispensable.

### Si les PJ n'ont pas compris que les tombes sont un verrou (Couche 2)

- **Thorgar** peut le dire explicitement si les PJ lui demandent pourquoi les rites sont importants.
- **Olane** peut faire le lien entre les runes et les rites si les PJ lui montent les fragments d'os.
- **Le retour au Cimetière** (Acte III du Scénario 1) force la révélation : cinq tombes sur sept, bourdonnement du Puits.

### Si les PJ n'ont pas compris que Thade est impliqué (Couche 3)

- **La Résistance** (Mara, le Collecteur) peut fournir le lien entre les caisses de Caldris et l'Université.
- **Olane** dit explicitement : "La Tour. Regardez la Tour."
- **La mort de Jaren** avec la rune de Dissection à Distance est un indice fort — si les PJ ne le relient pas à Thade, un PNJ (Olane, Thorgar) peut le faire.

### Si les PJ n'ont pas le protocole S-01 (Couche 3)

- **Le laboratoire d'Elian Voss** (Scénario 2) contient le protocole complet.
- **Les cahiers de Thade** (Scénario 2, Laboratoire de Verre) révèlent l'histoire entière.
- L'absence de S-01 au Scénario 1 rend le Scénario 2 plus difficile mais pas bloqué.

### Si les PJ n'ont pas les vérités sur Sealine (Couche 9)

- Le combat final est plus difficile (Phase 2 sans fissuration de la Larme).
- Sealine elle-même peut révéler les vérités pendant la Conversation à Trois.
- Le final est plus sombre : les PJ combattent Thade par la force sans comprendre pourquoi.

## Synthèse : les 3 révélations indispensables par scénario

### Scénario 1
1. **Les tombes sont un verrou** (Couche 2) — via Thorgar, les runes, le retour au Cimetière.
2. **Thade prélève les ancrages** (Couche 3) — via la rune de Jaren, le coffret plombé, les outils d'Université.
3. **Les PJ ne sont plus sûrs de leur employeur** (Couche 3 → 4) — via la mort de Jaren, le parfum de lavande, le choix de mots.

### Scénario 2
1. **Thade a préparé le rituel pendant 8 ans** (Couche 5) — via le registre de la Réserve, l'ardoise du 6e étage.
2. **La Larme de Vael est le catalyseur** (Couche 6) — via le schéma d'Elian, l'annotation de Sealine.
3. **La Tour est le dispositif** (Couche 7) — via les flux détournés, la cuve, les cahiers.

### Scénario 3
1. **Les vérités sur Sealine fissurent la Larme** (Couche 9) — via les cahiers, les patients, les bocaux, l'annotation.
2. **La Larme est le catalyseur du vortex** (Couche 9) — via Art de la magie DD 18 ou les connaissances accumulées.
3. **Le choix final appartient aux PJ** (Couche 10) — via Sealine elle-même.
